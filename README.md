## **Bed Rot Justifier**

Had a completely unproductive day? Good. You deserve it. And we'll prove it.

**Bed Rot Justifier** is a web app that I made to not make me so guilty for doomscrolling all day. It that takes your laziest, most unproductive day and 
generates a completely serious, totally valid justification for why none of it was 
your fault. Blame capitalism. Blame Mercury retrograde. Blame your WiFi provider because it's never your fault for just taking a break (even if it means procrastinating on that long assignment that you shouldve completed by now...)


## How to Run

1. Clone this repo
2. Install dependencies:
```bash
   pip install flask google-genai python-dotenv
```
3. Create a `.env` file in the root folder and add your gemini api key there
